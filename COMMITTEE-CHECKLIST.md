# PayEvidence — Estonia Startup Path Checklist

Authoritative: [PBGB start-up entrepreneurs](https://www.politsei.ee/en/instructions/residence-permit-for-business/for-start-up-entrepreneurs) · [Startup Estonia foreign founder](https://startupestonia.ee/startup-visa/foreign-founder/)

## Product readiness
- [ ] Working MVP / demo (not deck-only)
- [ ] Clear scalable SaaS model (not consultancy)
- [ ] Founder can explain tech + market in 5 minutes

## Company
- [ ] Estonian company (OÜ) — required for startup TRP track
- [ ] e-Residency (optional but practical for remote company admin before move)
- [ ] Business plan + description matching **startup** definition (innovative, scalable)

## Startup Expert Committee
- [ ] Apply for evaluation / exemption path per current Startup Estonia + PBGB process
- [ ] Positive committee decision (often ~10 working days once complete)
- [ ] Keep decision letter for TRP/visa file

## Temporary residence (after committee)
- [ ] TRP for business (startup) application (or startup D-visa bridge then TRP in Estonia)
- [ ] Income proof ≈ 4× subsistence (~€880/mo with 2026 subsistence €220 — confirm live figures)
- [ ] Health insurance plan
- [ ] Intention to settle; later: register address in Population Register
- [ ] State fees per PBGB schedule

## After arrival (years 1–5 toward permanent residence)
- [ ] Actually live in Estonia; run the company; limited absences
- [ ] Tervisekassa coverage via proper contributions
- [ ] Estonian language → **B1** before long-term resident application
- [ ] After ~5 years on qualifying TRP → long-term resident permit application

## Do not confuse
- e-Residency ≠ right to live in Estonia
- Digital Nomad Visa ≠ residence years toward PR
- PayEvidence must stay a **product company**, not a one-man audit consultancy
