How a pack gets built

1. Ingest

Payment-stack artifacts — API access logs, config snapshots, control-test results, change records — without taking cardholder data.

2. Map and score

Each artifact is mapped to a PCI DSS control and scored pass, gap, or stale from freshness rules.

3. Export

Dated evidence packs (HTML and PDF) a compliance lead can hand to an auditor, with the control map attached.

Who it’s for

Payment companies and fintechs facing PCI audits — compliance leads, PCI program owners, and CISOs who still rebuild proof in spreadsheets every cycle.

The public demo is the synthetic NordicPay tenant. It is not a QSA, and it does not store cardholder data.
